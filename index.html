關於這個專案

這個專案最初是「給每個人看自己碳足跡」的教育計算器。發展到現在，焦點變成：幫永續農戶把「碳數據 + 經營頭腦」結合 — 因為光有環境意識，撐不起一個可長期經營的農場。

現在的儀表板裡有：本月該做的 3 件事（即時生成）、現金流月曆（找出缺口月）、定價工作室（成本反推 7 種通路）、補助申請草稿（一鍵複製可直接 Email）、買家提案單（A4 列印）、議價演練（5 種買家刁難）、投資回收計算機（8 種做法回本期）、同儕比較、ERP 紀錄。所有排放係數仍採台灣官方資料（能源署 113 年電力、環境部燃料）。

完全免費、無需註冊、無後端、無 cookie — 你的網址就是你的「帳號」（資料以 base64 編碼存在 URL 的 #data 片段中，不會上傳到任何伺服器）。所有計算都在你的瀏覽器中完成。

本工具僅供教育與經營決策初步估算，不能取代正式的 ISO 14064 組織型溫室氣體盤查、也不構成任何法定申報依據。補助申請草稿、定價推算、ROI 預估皆為保守起點，實際申請、出價、投資請以主管機關 / 買家 / 供應商當年資訊為準。
